# Audit et archivage du 5 novembre 2026

Neuf scripts locaux termines ou abandonnes sont archives avec empreintes identiques.
Dans cette selection publique, la recette D auparavant exposee comme module courant
passe dans `historique/voix-abandonnees/`, sous forme de texte non executable.
Le banc vocal ne conserve que les options natives de la reference originale ;
les anciennes recettes sont refusees avant de charger les outils de mesure.

358 tests logiciels du laboratoire passent. Les autres modules de fonctionnement
inspectes sont inchanges. Aucun modele, microphone, souvenir ou canal externe
n'a ete lance pour cet audit. Les ressources et donnees privees restent exclues.

Dans l'installation locale, 100 temporaires Git anciens ont ete supprimes apres
quarantaine et controle de connectivite : environ601 Go logiques. Les exclusions
Git ont ete completees. Les temporaires recents restent conserves et la maintenance
automatique locale est suspendue ; la cause de chaque interruption n'est pas etablie.
Ce nettoyage n'est pas une commande a executer sur un autre depot sans diagnostic.

Refactorisation suivante identifiee : separer le cycle de vie des services de la
boucle de conversation de l'interface. Elle n'est pas incluse dans cette publication.
Les copies identiques entre l'installation originale et le laboratoire restent
volontaires tant que les deux installations doivent fonctionner independamment.
