# Rappel de memoire : corrections et limites

Etat du 5 novembre 2026. Le proprietaire accepte cette version comme base
viable, avec ses limites, et demande de poursuivre. Le modele, la voix, le
backend et les sources originales sont conserves. La memoire n'est pas
declaree parfaitement fiable ; les retours d'usage guideront ses ameliorations.

## Corrections actives

Le budget de la reponse finale compte le schema reel et le contexte transmis.
Les sources retenues restent entieres. Si le budget est depasse, les elements
facultatifs puis les contextes et preuves les moins prioritaires sont retires ;
le schema et les references admissibles sont reconstruits a chaque passage.
Une source retiree ne peut plus etre citee. Un contenu fixe trop grand ou une
mesure invalide provoque un refus avant generation, sans modifier les archives.

Pour le rappel personnel, le meilleur temoin de recherche passe en premiere
place, suivi des choix du reclassement. Le second temoin reste disponible,
sans prendre la place d'une correction reclassee dans un budget de deux sources.
L'ordre du dialogue general reste conserve. Aucun nouvel appel au modele
n'est ajoute par cette priorite.

Le lecteur factuel recoit une indication d'identite (Alice), de tutoiement et
de precision : ne pas ajouter de motifs, intentions ou consequences absents
des sources. Les citations gardent leur formulation. Les longues consignes
et la suppression des doublons essayees sont ecartees apres regressions.
Les candidats adaptatifs publies restent experimentaux et inactifs ; leurs
adaptations suivent le nouveau budget sans installer leurs variantes.

## Mesures locales et portee

Sur un lot prive autorise de 20 rappels : 20 reponses jugees acceptables,
dont 17 sans reserve. Les trois reserves concernent precision, modalite et
ambiguite. Le code installe reproduit les 20 reponses de la variante retenue.
Cette evaluation qualitative par assistant ne vaut pas validation universelle.
Aucune question, conversation ou reponse privee n'est publiee ici.

Sur 16 cas fictifs reserves : 14 corrects, 2 partiels, 0 incorrect, comme la
reference initiale ; ton conforme 16/16 contre 3/16 avant correction, citations
exactes 2/2. Les sources ont ete fermees puis rouvertes ; ce n'est ni un
redemarrage Windows ni un essai vocal interactif. La confirmation native finale
n'est pas un nouveau test aveugle. Le critere anterieurement propose de 36/40
sur cas reserves n'a pas ete mesure et n'est pas revendique.

485 tests logiciels ont reussi dans l'installation locale. Ce nombre decrit
la suite locale, pas une suite reproductible integralement depuis cette copie
publique : certains bancs, ressources, configurations et preuves sont exclus.
Les tests publies de budget et de priorite utilisent des sources fictives.
Les sources originales sont restees intactes ; les donnees temporaires ont
ete nettoyees. Aucun microphone, son diffuse ou message externe dans les essais.

Des omissions, nuances perdues ou erreurs de provenance restent possibles.
Le jugement conversationnel est reporte ; l'oubli public par commande reste
hors de cette passe. Une bonne lecture ne prouve pas la verite scientifique
d'un propos archive. Les souvenirs et rapports bruts restent prives.

## Suite retenue

Prochaine etape : concevoir puis verifier une initiative de parole bornee,
avec silence, interruption et arret humain respectes. Elle n'est pas activee
par cette publication. Aucun changement de modele ni de backend n'est prevu.
